# Toy Haven — COMP40053 Assignment 3

A responsive, multi-page front-end toy store built with HTML5, CSS3 and JavaScript.

## Pages
Home, Products, Shopping Cart, Checkout, My Collection, Support & Feedback, plus optional Sign Up and Register pages matching the provided UI guide.

## Required functionality
- Auto-rotating hero image slider with Toys, Figurines, Board Games and Diecast Cars
- Featured products
- Search + category filters
- Product detail modal
- Dynamic shopping cart
- localStorage persistence
- Checkout validation and order history
- Wishlist/Collection statuses
- Feedback form and FAQ accordion
- Newsletter localStorage
- Responsive hamburger menu
- PWA manifest + service worker
- Quick action buttons on every page: Shop Now, Support and Feedback

## GitHub Pages
Create a repository, upload the contents of this folder, then use Settings → Pages → Deploy from branch → main → root.

## Testing
Run W3C HTML validation, W3C CSS validation, WAVE, Lighthouse on desktop/mobile, and test mobile/tablet/desktop layouts before submission.


### Typography
The website uses the **Poppins** Google Font consistently across all pages through `css/common.css`.
